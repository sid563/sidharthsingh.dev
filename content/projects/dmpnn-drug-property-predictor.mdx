## Summary

Final-year work at VIT. Developed a D-MPNN model with ensemble learning for ADME property prediction, integrating substructure features to improve screening accuracy. Reached an R² of 0.9607 on the held-out set.

It is the project that taught me how much of machine learning is data plumbing, which turned out to be good preparation for backend work.
